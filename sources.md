# Data sources
Ephemerisdes: JPL HORIZON System
Topographic data: USGS LOLA Planetary Maps (https://planetarymaps.usgs.gov/)
Offline ephemerides and lunar orientation (optional street view mode): JPL DE421 (de421.bsp, moon_pa_de421_1900-2050.bpc), loaded through Skyfield (https://rhodesmill.org/skyfield/)
Moon globe texture: three.js examples, moon_1024.jpg (https://github.com/mrdoob/three.js/blob/r160/examples/textures/planets/moon_1024.jpg)
Rover inspiration (used as a reference only, no code or assets included): Space-Ros GitHub Repo (https://github.com/space-ros/demos/blob/main/curiosity_rover/)
Moon 3d image (https://eyes.nasa.gov/apps/solar-system/#/earth/moons/moon?embed=true)
List of notable Moon sites: USGS Planetary Names (https://planetarynames.wr.usgs.gov/)
List of Apollo missions landing sites: quickmap
